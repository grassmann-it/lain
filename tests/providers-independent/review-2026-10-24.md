## Boundaries verified in source

- All five new provider manifests are present and covered by the Host catalog
  resource glob. Host registration includes Fireworks, Gemini Monitoring and the
  passive Groq adapter. Monitor GET/PUT/DELETE endpoints share the existing local
  authentication and serialized mutation boundary.
- Connection setup derives compatible endpoint/protocol groups. Optional models
  are checked against the selected billing scope and permitted templates before
  secret persistence. Connection-only setup activates no routes; default names do
  not replace existing custom names; selected routes retain the account identity.
- Monitor credentials live under their own account-bound private directory.
  `ProxyConfigurationWriter` and route bindings consume the inference SecretStore,
  never monitor files. Public monitor status has no secret field. Store/service
  validation checks account/provider identity and known provider resource bindings.
  No monitor refresh/revocation or speculative owned OAuth path is introduced.
- Separate Fireworks monitor tokens do not silently fall back to inference keys.
  Gemini Monitoring uses the external monitor access snapshot and its project,
  never the inference key. Wrong project/service/metric payloads are rejected;
  reported request usage has no inferred model limit or remaining quota.
- Passive Groq refresh supplies an empty credential and reads only the authenticated
  private observation endpoint. Capture checks selected credential, route provider,
  request, model and account identity. Original observed time survives refresh;
  reset time can shorten freshness; omitted windows are not merged into fresh events.
- Last-good identities include source, window, scope, scope ID and model. Metadata,
  data timestamp, provider update timestamp and approved ceiling remain distinct.
  Cloudflare's unavailable implementation and NVIDIA's qualified source boundary
  are expressed as guidance, without fabricated free-tier remainder.
- Desktop unverified/not-checked/unknown credentials are neutral. Missing, expired
  and actual authentication failures still have explicit warnings. Usage, balance
  and limit measurements do not acquire inferred percentage bars.
