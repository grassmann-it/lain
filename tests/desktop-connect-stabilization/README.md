# Connect and workspace stabilization

Run `./tests/desktop-connect-stabilization/run-private-xvfb.sh /tmp/lain-stabilization-evidence`
in the integrator's serialized build/runtime slot. Set `LAIN_DESKTOP_SKIP_BUILD=1`
for a previously built harness. The runner rejects inherited displays, owns its
Xvfb/Xauthority, and uses temporary HOME/XDG/LAIN_HOME. Only an in-memory,
allowlisted fixture can answer API requests. Only an explicitly clicked synthetic
Connect and model attachment can POST; browser, service, inference and provider operations are absent.

Checks cover mixed empty free credits and nonempty quota windows (F03), a
coordinate-stable adjacent wide inspector / separate narrow task page and focus return, common menu commands, distinct
Barebones/Simple/Advanced navigation, direct Gateway profiles, new-editor scroll
(F08), mounted drafts, private short Connect, unqualified device gating,45 existing model
entries, host Apply preview, explicit Monitor and offline Gateway. PNGs cover 1120×780,
800×560 and a user-resizable 640×420 Monitor. These are routed UI fixture checks;
they do not establish physical pointer, screenreader or live provider behavior.

Post-Connect model selection uses exact catalog connection IDs and only that
connection's templates. It reuses the saved private key and stable account ID,
carries the frozen configuration revision and account generation, requires
explicit multi-plan access, omits artificial single-plan fields, selects no
models by default and disables already-configured templates. The fixture
attaches two models, rejects any submitted key and verifies that Apply never
runs. Manual model access remains available in Models.

`dotnet run --project tests/client-connect-stabilization/ClientConnect.Stabilization.csproj`
checks the same production CLI renderers against in-memory typed quota/usage facts.
Full totals remain unknown; known reported subtotals retain measured/eligible
coverage. Small and exact money values survive rendering. No real credentials,
local service, installation or provider is used.
