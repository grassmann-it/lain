# PUB-06 · Fresh-user flow and exact-artifact delivery

Owner: existing STAB-08 integrator/independent acceptance lane. Depends on00 and
included package outcomes; prepares cases early, freezes candidate only after merge.

## Outcome and ownership

A real new user can install and understand supported Monitor/Gateway/client paths,
then update/restore without losing accounts/history/settings. Own existing build/
packaging/acceptance scripts and final release/install/support documentation.
Domain source changes return to01–05/08 or STAB/REC owner. No separate publisher.

## Tasks

- Reconcile docs/install flags against current lifecycle: UI ensure/start, login
  autostart options, explicit Stop and window-closed operation, Monitor without
  Core. Don't copy obsolete installer prose or require client patches for quotas.
- Freeze source, dependency locks, exact component/client versions and notices;
  version choice through00. Confirm redistribution/patch limits and original
  restore paths; no silent unknown VS Code update patching.
- Fresh isolated Monitor/Gateway install outside repo cwd, account/connect outcome,
  optional Gateway/route/Apply/client export, function continuation, image input,
  automatic compaction on exact native fixtures; authorized live scope separately.
- Close/reopen/restart, pending desired!=applied, update and rollback/recovery;
  preserve account names, history, profiles, credential retirement/rotation fences
  and unrelated client configs. App rollback isn't automatically data/OAuth rollback.
- Verify source/package/native/install/report hashes and new disabled-first recorder
  behavior only if REC included. No local repaired catalog masquerades as fresh
  exported package behavior.

## Acceptance and release boundary

A self-contained evidence receipt identifies every claimed platform/client/model/
provider path and unsupported cases. Historical test counts aren't inherited by
new artifacts. Safe public docs/support matrix and no credentials/private traffic
in deliverables. Earlier all-model qualification requirement not silently waived;
spend/scope decisions before any expensive live matrix.

Return concrete archives/checksums/source/notices, tested commands and outcomes,
config/migration/rollback guide and blockers. Preparing a package does not publish
it; no GitHub upload/tag/production install or real request follows automatically
from this planning packet. Public action happens only for the reviewed artifact.
