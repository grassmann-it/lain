## Three affordable subscription recommendations

These are **alternatives for different needs**, not a recommended mandatory bundle
of three. Prices are monthly USD list prices; German checkout/taxes are unverified.
The assessment concerns usable product features, not referral compensation.

| Choice | Price | Why it is interesting | Key limitation |
| --- | ---: | --- | --- |
| **[NanoGPT Pro](https://nano-gpt.com/pricing)** | **$12/month** | Broad open-model pool, explicitly available through the API too; 60 million input tokens/week, with no separate charge for output from included models | The exact model variant must be included. Closed models, certain variants, paid tools and a fixed provider selection can consume credit. |
| **[Synthetic Go](https://synthetic.new/pricing)** | **$9/month** | Affordable open-model pool with API access and replenishing weekly quota | Shared pool weighted by model; no fixed token allowance promised. Move to Standard at $30 only after observing a bottleneck. |
| **[OpenCode Go](https://opencode.ai/go)** | **$10/month** | Curated coding mix, with use by other agents explicitly supported | Single workspace and coding traffic; preserve session/client identifiers. Time windows apply simultaneously, rather than providing additive model credits. |

**For Lain, choose one first and check the model routes you want.** NanoGPT is the
strongest starting candidate for a large open-model pool. Synthetic is a cheaper
alternative with a different limit model; OpenCode is especially worthwhile for
its specific coding mix. Model overlap alone does not justify a second
subscription. Publicly confirmed plan terms are not a new live qualification of
the corresponding installed Lain route.

**Additional option:** [Kilo Pass Starter](https://kilo.ai/pricing/kilo-pass/), from
**$19/month**, is a credit subscription with a bonus, not unlimited usage. The
[Gateway](https://kilo.ai/gateway) allows external API use. However, the current
Lain catalog routes are explicitly free routes; check Pass/endpoint coverage
separately before buying. Do not recommend it as a Lain Pass subscription proven
to work today.

## An easy free start

- **[Groq Free](https://console.groq.com/docs/rate-limits):** useful for small,
  fast API tasks. Tight TPM limits can rule out large coding prompts; the lack of
  a card requirement is inferred from the upgrade flow.
- **[Gemini API Free](https://ai.google.dev/gemini-api/docs/billing):** an additional
  model family without paid billing; limits depend on the model and project.
- **[Requesty Free](https://www.requesty.ai/pricing):** explicitly requires no card,
  [200 requests/day and 20/min](https://docs.requesty.ai/features/free-models),
  shared across the organization. Lain end-to-end acceptance is separate.
- **One-time trial:** [Inception](https://docs.inceptionlabs.ai/get-started)
  states 100 million starting tokens without payment details. Expiry and specific
  rate limits remain unknown; this is not a replenishing free pool.

SambaNova still requires no card, but is tighter at 20 requests/day. OpenRouter
allows only 50 free requests/day without buying credit. Alibaba/Nebius are not
the first recommendation for an easy free start because of the transition to
charges and the card requirement, respectively. Details and primary sources are
in the [free-tier report](provider-research-retry-free-2026-10-26.md).
